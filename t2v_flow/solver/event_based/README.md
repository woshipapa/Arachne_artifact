# t2v_flow/solver/event_based

Event-based scheduling formulations and heuristic solvers.

## Files
- dual_greed.py: Enhanced heuristic with multiple priority rules and sampling.
- qifashi.py: Heuristic list scheduler with LPT priority rule.
- yichuan.py: Genetic algorithm search for SP schedules.
- pyo.py: Pyomo event-based MIP formulation.
- test.py: PuLP MILP event-based formulation and solve.
