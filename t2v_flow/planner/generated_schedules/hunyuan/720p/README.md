# Generated schedules - Hunyuan 720p (collection)

Base schedules and traces for Hunyuan 720p, plus variant and method subdirectories.

## Files
- schedule_*.yaml: Base schedule definitions.
- schedule_*_trace.csv: Timeline traces for per-rank analysis.

## Subdirectories
- flex_sp, genetic, megatron-lm: Method-specific schedules.
- 53, 81, 8nodes, 4nodes: Variant and scale-specific experiments.
- 129_w_intra, 129_wo_mapper, 129_w_inter: Variant schedules for 129 settings.
