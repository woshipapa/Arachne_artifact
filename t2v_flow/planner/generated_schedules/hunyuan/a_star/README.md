# Generated schedules

Context: Model: Hunyuan. Method: A* search.

## Files
- schedule_*.yaml: schedule definitions for a single run or iteration.
- schedule_*_trace.csv: per-rank timeline traces when present.
- schedule_*_tasks.json: optional task metadata when present.

## Notes
- These files are generated by the planner and scheduler tooling in t2v_flow/planner.
- Use t2v_flow/planner/generated_schedules/plot_png_from_csv.py to visualize trace CSVs.
